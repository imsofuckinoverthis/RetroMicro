# RetroMicro

An early-2000s-inspired virtual computer and gaming world. This repository is the standalone RetroMicro project and is separate from Cardexx.

## First prototype
The current `index.html` is a mobile-responsive interactive preview with:
- RetroMicro startup screen
- First-time setup flow
- Username and computer-name selection
- Three free starter wallpapers
- Desktop with clickable icons and basic windows
- Local browser storage for demo preferences

## Important
This is a front-end prototype, not yet a native Android/iOS app. It does not create real accounts, verify email, store passwords, sync data across devices, process purchases, or provide production security. Do not enter real passwords or sensitive information.

The next stage is to turn this foundation into an installable mobile app, then add secure authentication, synced profiles, character creation, and original hybrid games.
